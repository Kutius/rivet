# Security Policy

Rivet is beta software. The supported version is the latest 0.1.0-beta.x release.

Do not open a public issue for a vulnerability. Use the repository's private security advisory flow once the repository is published; before that, contact the maintainer directly.

Include the Rivet version (rv --version), the command, the operating system, and the relevant output. Do not include private signing keys or tokens.

The detailed trust model is in [docs/SECURITY.md](docs/SECURITY.md).
