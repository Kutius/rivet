# Rivet main repository

This is the official Rivet main catalog. It is served at:

~~~text
https://kutius.github.io/rivet/index.json
https://kutius.github.io/rivet/index.json.sig
~~~

## Layout

~~~text
packages/*.toml       package manifests
artifacts/            demo artifacts checked in for the hello package
index.json            generated by `rv repo build`
index.json.sig        Ed25519 signature over the exact index.json bytes
~~~

## Maintainer workflow

1. Add or edit `packages/<name>-<version>.toml`.
2. Point `url` at a stable upstream release URL, or commit a small artifact under `artifacts/`.
3. Build the index:

   ~~~powershell
   rv repo build repo\main
   ~~~
4. Sign it with the offline key:

   ~~~powershell
   rv repo sign repo\main --key <offline-key-path>
   ~~~
5. Commit the manifest, `index.json`, and `index.json.sig`.
6. Push to master. The Pages workflow publishes the catalog.

The private key is never committed and must remain offline. The public key is embedded in the client as the default trusted catalog key.
