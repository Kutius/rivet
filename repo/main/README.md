# Rivet main repository

This is a seed main repository for Rivet.

## Layout

~~~text
packages/*.toml       package manifests
artifacts/            demo artifacts checked in for the seed package
index.json            generated by `rv repo build`
~~~

## Maintainer workflow

1. Add or edit `packages/<name>-<version>.toml`.
2. Put the artifact somewhere stable. For the personal setup, either commit small artifacts under `artifacts/` or point `url` at the upstream release URL.
3. Build the index:

   ~~~powershell
   rv repo build repo\main
   ~~~

4. Commit the package manifest and `index.json`.
5. Point clients at the published `index.json` with:

   ~~~powershell
   rv config set main_index https://example.com/rivet/index.json
   ~~~

   or set `RIVET_MAIN_INDEX` for a local test.

The demo package `hello` has two versions and a tiny `hello.cmd` payload. It is intentionally trivial; use it to verify install, shim, upgrade, rollback, and remove without external downloads.
